# OrbCharts 文件

OrbCharts 是一個**資料驅動**的 JavaScript 圖表函式庫，以 D3.js 與 RxJS 為基礎。它的核心概念是：先準備**資料格式**，再選擇 **Plugin** 來呈現；每個 Plugin 由可組合的 **Layer** 構成，同一份資料能對應多種視覺呈現。

> **第一次使用？** 建議從 [安裝](/docs/getting-started/installation) 與 [第一個圖表](/docs/getting-started/first-chart) 開始，再閱讀 [核心概念](/docs/getting-started/core-concepts)。
